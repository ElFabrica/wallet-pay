# WalletPay Docs

## Orientacao geral

- Consulte este documento antes de ler qualquer spec em `docs/specs`.
- O documento unico do usuario, incluindo RG quando aplicavel, deve ser tratado no dominio e na API como `document`.
- A coluna `users.document` e a fonte de verdade para esse dado, conforme `src/main/resources/db/migration/V1__create_users_and_wallets.sql`.
